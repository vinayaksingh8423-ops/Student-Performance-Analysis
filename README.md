
# Student Performance Analysis System

## Project Description
The Student Performance Analysis System is a Python-based data analysis project that analyzes students' marks in different subjects. It calculates average marks, identifies the top performer, checks Pass/Fail status, and displays results using a bar chart.

## Objectives
- Analyze students' academic performance.
- Calculate average marks in different subjects.
- Identify the highest-performing student.
- Display Pass/Fail results.
- Visualize student performance using a graph.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

## Features
1. Reads student data from a CSV file.
2. Calculates individual average marks.
3. Finds the top performer.
4. Calculates subject-wise averages.
5. Displays Pass/Fail status.
6. Generates a performance bar chart.

## Project Files
- main.py - Main Python program
- students.csv - Student marks dataset
- performance_chart.png - Generated bar chart

## How to Run
1. Install Python.
2. Install the required libraries:
   pip install pandas matplotlib
3. Run the program:
   python main.py

## Conclusion
This project demonstrates how Python can be used to analyze student data and present useful information through calculations and visualizations.
